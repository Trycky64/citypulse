# CityPulse

Vue 3 + TypeScript + Vite + Tailwind. Données urbaines temps réel (météo, air, scores).

## Stack
- Vue 3 (Composition API), Vite, TypeScript
- TailwindCSS
- Leaflet (carte), Chart.js (graph)
- Pinia (state), Vue Router
- Axios + Zod (HTTP + validation)

## Lancer
```bash
npm i
cp .env.example .env
npm run dev
